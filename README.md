# Box Bash Island

단순한 3D 박스 캐릭터가 작은 섬 맵에서 이동, 점프, 몸통 박치기를 테스트하는 HTML 게임 1단계 프로토타입입니다.

## 실행

정적 파일만 사용합니다. 로컬에서는 `index.html`을 브라우저로 열면 됩니다.

조작:

- `WASD` 또는 방향키: 이동
- `Space`: 점프
- 마우스 왼쪽 클릭: 몸통 박치기

## 1단계 범위

- Three.js 기반 3D 장면
- 산, 바다, 평지로 구성된 단순 맵
- 박스형 플레이어 캐릭터
- 점프와 몸통 박치기
- 로컬 AI 캐릭터 몇 명
- HP, 넉백, 리스폰

## 다음 단계

2단계에서는 WebSocket 서버를 추가하고, 클라이언트는 입력만 보내며 서버가 위치/충돌/전투 결과를 계산하는 서버 권위형 구조로 전환합니다.
