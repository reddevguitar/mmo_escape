# Box Bash Island

단순한 3D 박스 캐릭터가 작은 섬 맵에서 이동, 점프, 몸통 박치기를 테스트하는 HTML 게임 2단계 프로토타입입니다.

2단계부터는 WebSocket 서버가 월드 상태를 권위적으로 계산합니다. 클라이언트는 키보드/마우스 입력만 보내고, 서버가 위치, 점프, 충돌, 몸통 박치기, HP, 리스폰을 계산해 모든 접속자에게 브로드캐스트합니다.

## 실행

```bash
npm install
npm start
```

브라우저에서 접속:

```text
http://localhost:8080
```

같은 네트워크의 다른 기기에서는 맥미니의 내부 IP를 사용합니다.

```text
http://맥미니_IP:8080
```

조작:

- `WASD` 또는 방향키: 이동
- `Space`: 점프
- 마우스 조준 + 왼쪽 클릭: 몸통 박치기

## 2단계 범위

- Three.js 기반 3D 장면
- 산, 바다, 평지로 구성된 단순 맵
- 박스형 플레이어 캐릭터
- Node.js 정적 파일 서버
- WebSocket 접속/퇴장 관리
- 서버 권위형 이동, 점프, 몸통 박치기
- 서버 권위형 충돌, HP, 넉백, 리스폰
- 30 tick/sec 게임 루프
- 20 snapshot/sec 상태 브로드캐스트
