# DUCKSCAPE — 오리들의 탈출 🦆

덕코브(Escape from Duckov)·타르코브 스타일의 **탑다운 익스트랙션 슈터 웹게임**입니다.
은신처에서 장비를 챙겨 출격하고, 상자와 시체를 뒤져 전리품을 모은 뒤, 제한 시간 안에 탈출 지점까지 살아서 돌아오세요.
죽으면 가져간 장비를 모두 잃습니다. 보안 컨테이너 안의 물건만 남습니다.

빌드 과정이 없는 순수 HTML + ES 모듈 + Canvas 2D 게임입니다. 외부 이미지·사운드 파일 없이 그래픽과 효과음을 모두 코드로 그리고 합성합니다.

## 실행

```bash
npm start
```

브라우저에서 `http://localhost:8080` 을 엽니다. (포트 변경: `PORT=3000 npm start`)

정적 파일만으로 동작하므로 `npx serve`, GitHub Pages 같은 아무 정적 호스팅에 올려도 됩니다.
ES 모듈을 쓰기 때문에 `index.html`을 파일로 직접 여는 대신 HTTP 서버로 열어야 합니다.

진행 상황(창고, 돈, 레벨, 의뢰, 시설)은 브라우저 `localStorage`에 자동 저장됩니다.

## 조작

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 조준 |
| 좌클릭 | 사격 (무기가 없으면 부리로 쪼기) |
| 우클릭 (누르고 있기) | 정밀 조준 — 시야가 멀어지고 탄퍼짐 감소, 이동 느려짐 |
| Shift | 달리기 (스태미나 소모, 발소리 큼) |
| C / Ctrl | 웅크리기 (조용히 이동, 적에게 덜 발견됨) |
| R | 재장전 (가방/주머니의 같은 구경 탄약 사용) |
| F | 상자·시체 수색 / 문 열고 닫기 |
| Tab | 인벤토리 (열어도 시간은 흐릅니다) |
| 1 / 2 / 마우스 휠 | 무기 교체 |
| 3 ~ 6 | 주머니 1~4번 칸 아이템 사용 (붕대, 의료품, 음식) |
| G | 수류탄 투척 (조준한 곳으로) |
| M | 지도 (탐색한 지역, 탈출 지점) |
| Esc | 일시정지 / 설정 / 레이드 포기 |

인벤토리: 드래그로 이동, **드래그 중 R로 회전**, Shift+클릭 빠른 이동, 우클릭 메뉴(사용/장착/탄 빼기/나누기/판매/버리기), 탄약을 총 위에 떨어뜨리면 장전.

## 게임 시스템

### 은신처
- **장비·창고**: 타르코브식 그리드 인벤토리. 주무기·보조무기·헬멧·방탄복·가방 슬롯, 주머니(1칸 4개), 보안 컨테이너, 창고
- **상인 (마담 꽥)**: 구매(가치의 120%) / 판매(가치의 60%). 플레이어 레벨 4·8에 신뢰도가 올라 더 좋은 물건이 열립니다
- **의뢰 11개**: 탈출·처치·수색·아이템 납품. 보상은 돈, 경험치, 장비
- **시설**: 창고 확장, 보안 컨테이너 확장, 훈련장(최대 체력 증가). 돈과 전리품 재료가 필요합니다

### 레이드
- **지역 3곳**: 갈대 농장(입문) · 갈대 농장 야간(시야 좁음, 전리품 x1.35) · 폐공장 지대(용병, 보스 대왕 거위). 지형은 시드 고정이라 매번 같고, 전리품과 적 배치는 매번 바뀝니다
- **시야**: 바라보는 방향의 부채꼴 + 주변 근거리만 보입니다. 벽과 나무는 시야를 막고, 창문·철망·낮은 엄폐물은 시야가 통과합니다. 등 뒤의 적은 총성·발소리·꽥! 소리로 알아채야 합니다
- **수색**: 컨테이너를 열면 아이템이 하나씩 드러납니다. 희귀할수록 오래 걸립니다
- **전투**: 9종 무기(권총·기관단총·산탄총·돌격소총·지정사수소총·기관총), 4종 구경 × 일반탄/철갑탄, 탄퍼짐·반동·사거리 감쇠
- **방어구**: 등급(1~5)과 내구도. 탄의 관통력이 낮으면 막히고 둔상만 입습니다. 맞을수록 내구도가 떨어집니다
- **엄폐**: 모래주머니·차량·가구 같은 낮은 엄폐물은 멀리서 쏜 총알을 막고, 바로 붙어 있으면 그 너머로 쏠 수 있습니다
- **생존**: 체력, 출혈(붕대로 멈춤), 에너지·수분(바닥나면 체력 감소), 스태미나, 소지 무게(22kg 초과 시 느려짐)
- **적 AI**: 순찰 → 의심(소리 조사) → 교전(반응 시간, 점사, 거리 유지, 엄폐물 우회) → 수색. 동료에게 알리고, 체력이 낮으면 치료하고, 용병은 수류탄을 던집니다. 시간이 지나면 증원이 옵니다
- **탈출**: 출격마다 3~4개의 탈출 지점이 열립니다. 구역 안에서 7초 버티면 성공. 시간이 다 되면 실종(MIA)
- 레이드 중 새로고침하거나 창을 닫으면 실종 처리됩니다 (타르코브 규칙)

## 프로젝트 구조

```
index.html, style.css      화면 뼈대와 스타일
server.js                  의존성 없는 정적 파일 서버
src/main.js                화면 전환 + 게임 루프
src/core/                  난수(시드), 유틸, DOM 헬퍼
src/data/                  아이템, 루팅 테이블, 적, 맵, 의뢰, 시설, 상인 데이터
src/systems/               인벤토리 그리드, 프로필 저장, 의뢰, 피해 계산, 레이드 결과 반영 (DOM 무관, 테스트 대상)
src/world/                 타일 맵(충돌·레이캐스트), 절차적 맵 생성기, A* 경로 탐색
src/game/                  레이드 시뮬레이션, 적 AI, 렌더러, 캐릭터 그리기, 입력, 효과음 합성
src/ui/                    은신처, 레이드 HUD/인벤토리, 드래그 앤 드롭, 아이콘, 각종 화면
test/                      node:test 단위 테스트
legacy/box-bash/           이전 3D 박스 박치기 멀티플레이 프로토타입 (npm run legacy)
```

## 검증

```bash
npm test        # 인벤토리, 저장, 의뢰, 피해 계산, 맵 연결성, 헤드리스 레이드 시뮬레이션
npm run check   # 전체 소스 문법 검사
```

## 데이터 수정

- 무기/아이템 수치: `src/data/items.js`
- 적 능력치(체력, 명중 오차, 반응 시간): `src/data/enemies.js`
- 상자별 전리품 확률: `src/data/loot.js`
- 맵 크기·적 수·전리품 배율·제한 시간: `src/data/maps.js`
- 의뢰: `src/data/quests.js`, 시설 비용: `src/data/hideout.js`, 상점 품목: `src/data/trader.js`

## 이전 프로토타입

이 저장소의 1~3단계였던 3D 박스 박치기 멀티플레이 프로토타입(Box Bash Island)은 `legacy/box-bash/`로 옮겼습니다.
`npm install && npm run legacy`로 그대로 실행할 수 있습니다.
