# Box Bash Island

단순한 3D 박스 캐릭터가 작은 섬 맵에서 이동, 점프, 몸통 박치기를 테스트하는 HTML 게임 3단계 프로토타입입니다.

WebSocket 서버가 월드 상태를 권위적으로 계산합니다. 클라이언트는 키보드/마우스 입력만 보내고, 서버가 위치, 점프, 충돌, 몸통 박치기, HP, 리스폰을 계산해 모든 접속자에게 브로드캐스트합니다.

## 실행

```bash
npm install
npm start
```

브라우저에서 접속:

```text
http://localhost:8080
```

같은 네트워크의 다른 기기에서는 맥미니의 내부 IP를 사용합니다.

```text
http://맥미니_IP:8080
```

조작:

- `WASD` 또는 방향키: 이동
- `Space`: 점프
- 마우스 조준 + 왼쪽 클릭: 몸통 박치기
- `Enter`: 채팅 입력

## 3단계 범위

- Three.js 기반 3D 장면
- 산, 바다, 평지로 구성된 단순 맵
- 박스형 플레이어 캐릭터
- Node.js 정적 파일 서버
- WebSocket 접속/퇴장 관리
- 서버 권위형 이동, 점프, 몸통 박치기
- 서버 권위형 충돌, HP, 넉백, 리스폰
- 닉네임 설정
- 접속/퇴장 시스템 메시지
- 간단한 채팅
- 접속자 목록과 킬/데스 표시
- 캐릭터 이름표
- 몸통 박치기/피격 이펙트
- `config.js` 기반 서버 설정 분리
- 30 tick/sec 게임 루프
- 20 snapshot/sec 상태 브로드캐스트

## 서버 설정

환경 변수로 일부 설정을 바꿀 수 있습니다.

```bash
PORT=8080 MAX_PLAYERS=64 TICK_RATE=30 SNAPSHOT_RATE=20 npm start
```

외부 공개 운영 메모는 `DEPLOY_MAC_MINI.md`를 참고하세요.
